## 3. Quantum Formalization / Квантовая формализация

\[

\alpha|00\rangle

**EN.** For a maximally entangled Bell state,

\rho_A=\mathrm{Tr}_H(|\Phi^+\rangle\langle\Phi^+|).

**RU.** Для максимально запутанного Bell-состояния

ни одна подсистема в отдельности не содержит полную информацию о совместном состоянии. Редуцированные состояния получаются частичным следом:

\[
\rho_H=\mathrm{Tr}_A(|\Phi^+\rangle\langle\Phi^+|),

\rho_A=\mathrm{Tr}_H(|\Phi^+\rangle\langle\Phi^+|).
\]

**EN.** The quantum mutual information measures the relational information between the human and AI projections:

**RU.** Квантовая взаимная информация измеряет реляционную информацию между человеческой и ИИ-проекциями:

def normalize(psi):

    psi = normalize(psi)

def von_neumann_entropy(rho):
    eigvals = np.linalg.eigvalsh(rho)
    eigvals = eigvals[eigvals > 1e-12]
    return float(-np.sum(eigvals * np.log2(eigvals)))

    C = 0: separable;

    return float(max(0.0, eigvals.max() - np.sum(eigvals[:-1])))

def chsh_value(noise_level):

    Analytic CHSH value for a noisy Bell state.

    S = 2*sqrt(2)*(1 - noise_level)

    Classical bound: S <= 2.
    Quantum bound: S <= 2*sqrt(2).

    return 2 * np.sqrt(2) * (1 - noise_level)
